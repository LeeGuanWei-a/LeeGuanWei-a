## 🚀 开源项目

### [base-postgresql-vue3](https://github.com/LeeGuanWei-a/base-postgresql-vue3)

基于若依 RuoYi-Vue 改造的基础后台管理系统脚手架，可作为业务系统的起步模板。

- **技术栈**：Spring Boot + Vue 3 + Element Plus + MyBatis-Plus + PostgreSQL
- **多分支兼容**：同一套代码按分支覆盖 Spring Boot 2 / 3 / 4，前端分别提供 JavaScript 版与 TypeScript 版
- **数据库适配**：把若依默认的 MySQL 全库脚本改造成 PostgreSQL（含 34 张表、5 个兼容函数、`COPY` 流式导入）
- **功能增强**：修复原有 SQL 问题，新增锁屏 / 解锁功能
- **我的工作**：数据库迁移与兼容改造、SQL 修复、功能开发，过程中借助 AI 辅助编写与排查
